# WaterSource 💧🔥

WaterSource is a lightweight Minecraft utility mod that highlights the **source block** of flowing water and lava.

When you find and block the source, the flow completely stops.  
No guessing, no unnecessary features — just clear source detection.

## ⭐ Features
- Detects the source block of flowing water
- Works for lava as well
- Simple visual highlight on the source block
- Lightweight and performance-friendly

## 📦 Required Library
WaterSource requires **Cloth Config** to run.
Download it from Modrinth:  
https://modrinth.com/mod/cloth-config
